# What is ACP?

<p class="lead">A shared conversation between a client<br>and an agent harness</p>

- The **client** presents the conversation and handles interaction
- The **agent** plans work and uses its tools to fulfill the conversation
- ACP carries **prompts, progress, permissions, and cancellation**

<p class="aside">Copilot CLI becomes an ACP agent with <code>copilot --acp</code></p>
