# Why ACP when we have the CLI?

| Use the CLI when… | Use ACP when… |
|---|---|
| A developer wants an interactive terminal | Your tool owns the interaction |
| A prompt and result are enough | Your UI needs structured progress |
| A command fits your shell pipeline | You need ongoing sessions and callbacks |
| Copilot's terminal UX fits the task | You want a reusable client interface |

**Example:** a custom review UI that wants to extend the functionality of the Copilot CLI beyond simple terminal interactions.
