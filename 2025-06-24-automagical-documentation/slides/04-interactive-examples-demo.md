## Slide Details

**Title:** Interactive Examples in Action  
**Subtitle:** Comment-based help becomes executable documentation

### Content
- Demonstrate the interactive examples within the documentation
- Show how examples from comment-based help are automatically recorded
- Display the asciinema terminal recordings embedded in the docs
- Show multiple examples with different complexity levels
- Highlight the visual appeal and usefulness of seeing actual output

### Imagery
- Screenshot of documentation page with embedded terminal recording

### Talking Notes
- Navigate to a function with rich examples in the documentation
- Play the embedded terminal recordings
- Explain that these recordings are generated automatically from the examples in the comment-based help
- Show how the recordings include both input commands and actual output
- Point out that these recordings are always current because they're regenerated with each code change
- Mention that viewers can see exactly what the output should look like
- Highlight how this makes the documentation both educational and debugging-friendly
- Note that if an example breaks, the recording will fail, alerting maintainers to issues
